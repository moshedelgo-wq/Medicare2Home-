MEDICARE V7 – חבילת פרסום

לפני העלאה לאוויר:
1. חובה להריץ SET_DOMAIN.bat ולהזין את הדומיין האמיתי ב-HTTPS. עד אז האתר מוגדר בכוונה NOINDEX ו-robots.txt חוסם סריקה.
2. לאחר ההרצה, העלה את תוכן התיקייה לשורש האתר.
3. בדוק שהאתר נפתח ב-HTTPS וש-/sitemap.xml ו-/robots.txt זמינים.
4. חבר Google Search Console ושלח sitemap.xml.
5. הטפסים בגרסה זו אינם שומרים מידע רפואי באתר: הם פותחים הודעת דוא״ל אל PHARMACY@MEDICARE.CO.IL. מסמכים יש לצרף למייל.
6. לפני פרסום מסחרי סופי יש להעביר את הנוסח המשפטי/פרטיות/נגישות לבדיקת הגורמים המוסמכים בארגון. לא הומצאו באתר הצהרות משפטיות שלא נמסרו למדיקר.

SEO שהוטמע:
- title ו-meta description ייחודיים ל-30 העמודים
- canonical + hreflang HE/EN/RU + x-default
- sitemap.xml + robots.txt
- Open Graph + Twitter cards
- Schema.org Pharmacy/MedicalBusiness + WebSite + BreadcrumbList + FAQPage
- alt, width/height, lazy loading ו-fetchpriority לתמונות
- ניווט crawlable וקישורים פנימיים
- מבנה responsive + Header מלא באנגלית וברוסית במסכי Desktop
- favicon + social share image

הערה: SEO אינו מבטיח דירוג. ביצועי Core Web Vitals תלויים גם בשרת, CDN, דומיין וטעינה בפועל לאחר הפרסום.
